01 · CORE PRODUCT

LightTrace · 光溯

面向复杂业务链路的企业级 Agent 智能诊断产品

WHAT IT IS

不是“问日志”，而是把一次复杂诊断组织成可执行、可追溯的产品流程。

当故障跨越多个应用、系统和团队，光溯从业务现象出发，先确认场景与边界，再组织链路、日志、工具与知识，让 Agent 沿证据逐步诊断，并把关键结论交还给人确认。

我的角色 · 产品 Owner负责 0→1 产品定义、Agent 工作流程、人机协作体验与质量闭环。

EFFICIENCY小时级 → 分钟级辅助诊断过程
QUALITY>85%根因命中率
